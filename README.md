# Cafeora Desktop for Windows

Installers for the Cafeora billing counter and kitchen (KOT) desktop app.

## Download

Get the latest **`Cafeora-Setup-x.y.z.exe`** from
[Releases → Latest](https://github.com/amitparmar-bt/cafeora-desktop-releases/releases/latest).

## Install

1. Run `Cafeora-Setup-x.y.z.exe` and follow the steps.
2. If Windows SmartScreen says "Windows protected your PC", choose **More info → Run anyway**.
3. Open the app and enter the activation details given to you by Cafeora support.

## Updates

Installed copies update themselves. The app checks this page at start-up and every 4 hours,
downloads new versions in the background and asks before restarting. Staff can also use
**Help → Check for updates…**.

Settings, activation and bills waiting to sync are kept across updates.
